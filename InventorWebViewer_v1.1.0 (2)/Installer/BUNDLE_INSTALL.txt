Inventor Web 3D Viewer – Installation
======================================

Option A — Manual (developers)
------------------------------
1. Build Release x64 in Visual Studio 2022
2. Copy InventorWebViewer.dll into:
     InventorWebViewer.bundle\Contents\
3. Copy the whole .bundle folder to:
     C:\ProgramData\Autodesk\ApplicationPlugins\
4. Restart Inventor → ribbon tab "Web 3D Viewer"

Option B — Inno Setup installer
-------------------------------
1. Build Release and ensure DLL is in bundle Contents\
2. Open Installer\InventorWebViewer.iss in Inno Setup 6
3. Compile → Output\InventorWebViewer_Setup_*.exe
4. Run the setup (admin). It installs to:
     %ProgramData%\Autodesk\ApplicationPlugins\InventorWebViewer.bundle\
5. Restart Inventor

Notes
-----
- Interop DLL is NOT copied (Copy Local = False) — Inventor provides it.
- Log file: %AppData%\InventorWebViewer\log.txt
- Add-in load log: %AppData%\InventorWebViewer\addin_load.log
- Supported: Inventor 2023–2026 (2025+ recommended, SeriesMin 29.0)
